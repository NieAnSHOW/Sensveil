# 免费使用与离线政策

版本：0.2 · 日期：2026-10-14 · 状态：当前产品基线

本文件保留原路径供现有链接使用。2026-10-14 用户决定 Sensveil 全面免费，原激活与离线许可协议草案废弃；旧计划、报告中的商业验证项仅作历史记录，不是当前发布门槛。产品依据见 [PRD](../product/PRD.md)。

## 使用规则

- 不限制配置应用数量，不区分免费与付费套餐，不设置使用到期日。
- 不提供购买、试用、激活、设备绑定或许可服务；首次启动满 120 小时与离线状态不影响功能。
- 不为商业目的创建或更新试用记录、设备私钥、公钥指纹或设备摘要，也不发送相关请求。
- 历史商业数据不再参与添加应用、保护判定或状态展示；数据缺失、损坏和旧到期状态不得导致功能降级。
- 升级保留应用、开关、顺序、暂停状态、保护效果和时段配置；配置迁移失败保留原文件并提示，不静默清空。

应用数量不设人为上限，不代表硬件可承担无限窗口；实际保护仍受权限、模糊引擎、硬件与已验证窗口支持矩阵约束。

## 离线与隐私

核心保护、配置和内置节假日日历判断在本地运行，无许可服务依赖，不增加后台联网。项目和作者 GitHub 链接仅在用户点击时交给系统浏览器打开；版本号从本地 Bundle 元数据读取，不暗示已实现在线更新检查。

默认无行为遥测，不收集应用列表、窗口标题、屏幕内容或设备绑定信息。若未来引入必要网络能力，须先更新 PRD、隐私说明与实现边界。

## 验证边界

当前验收须确认第三个及更多应用可添加、没有商业状态限制、断网时保护与配置可用、旧配置保持，且没有试用或激活服务请求。规则测试和构建通过不能代替真实模糊、窗口层级与权限验收。
