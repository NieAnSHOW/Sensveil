## 窄窗口布局集成验证

离屏使用真实 `NSHostingView` 与 `NavigationSplitView` 定位到：详情 `VStack` 的默认最小高度阻止收缩，造成内部原生分栏超出宿主内容高度。详情容器明确允许 `minHeight: 0` 后，原生分栏可按宿主高度收缩。此前无效的 `GeometryReader` 包装已回退，保留原 `Form` 自带滚动，不额外嵌套 `ScrollView`。

新增 `ManagementLayoutTests` 在 780 × 560pt 和 780 × 700pt 两个真实原生宿主视口内检查：`NSSplitView` 边界位于宿主内容区内、保留至少两个原生滚动视口且其高度不超过宿主内容高度，且时段文档高于视口、能够滚动。撤去 `minHeight: 0` 时两个尺寸合计出现 8 条溢出断言失败；恢复修复后该项测试 0 失败。这些自动集成检查已确认裁剪根因修复，不据此宣称最终可见保存区已复验。

临时布局探针已全部移除；正式集成测试保留用于回归。本记录不保存诊断中的实际坐标、用户配置或屏幕数据。
