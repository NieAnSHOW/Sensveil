## 本轮范围

沿用已有 schema 2：配置成功保存后，将 `blurLevel`、`showsProtectionLabel` 传入现有运行时和材料协调器。切档与文字开关不主动撤 panel，不清空层级失败锁存；应用聚焦、暂停、非保护时段、权限失败和窗口变化继续走已有清理流程。

三档复制此前单操作者在两个合成窗口观察到有明显模糊差异、均不可读的组合：下层 `.popover` 锚点保持，上层 standard=`.hudWindow`、enhanced=`.underWindowBackground`、strongest=`.popover`。不声明公开 blur radius，不以透明度/实色冒充档位，不把材料枚举名称当强度证明。本轮直接应用材料，不增加或宣称安全动画。

### 档位验收与顺序修正

用户随后明确“模糊档位实现已验收”，同时指出增强视觉上比最强更模糊。这是本机本场景的功能与顺序反馈，不自动扩展为全部系统设置、3 人评估或安全过渡通过。按此次观察，当前材料映射调整为标准=`.hudWindow`、增强=`.popover`、最强=`.underWindowBackground`；仅互换上层档位映射，底层仍固定 `.popover`，不更换已有叠层组合或用透明度/实色加强。配置中的 `standard/enhanced/strongest` 语义与用户已保存选择保留，无 schema 迁移，不修改用户配置。

PoC 同步互换材料与诊断名称，锚点语义由原 strongest 改为 enhanced，使实际底层仍为 `.popover`。不再声称锚点是最强材料或该动画已经具备最低安全模糊保证。映射顺序按操作者反馈修正，修后视觉顺序仍需同场景复验；系统材料无公开可控半径，不能凭枚举确认跨环境强弱。

修正验证：新映射先在组件测试观察到 4 个预期断言失败，修改后完整 171 项 XCTest 通过。回归检查往返切档维持同一材料/文字视图对象、底层 `.popover` 和全强度 alpha；独立审阅核对产品/PoC 映射、诊断名称与底层一致，未发现新增确认 bug。Release 构建、plist、严格 ad-hoc 签名及安装流程通过，新产品已运行于 `/Applications/Sensveil.app`。最终 GUI 显示辅助功能未授予，没有请求权限或改变用户配置；本轮未宣称已在新二进制上完成视觉排序复验。

每个 panel 配置不接收输入的居中守护文案，按实际文字尺寸判断是否容纳于目标矩形。文案关闭只隐藏文字，不撤材料；只有 `ProtectionStatus.protected` 才允许显示“Sensveil 守护中”。当前公开材料路径不能签发隐私证据，产品窗口仍为未验证请求，因此此文案保持隐藏；布局和状态门控可以实现并验证，不能由候选档位、AppKit绘制或圆角验收伪造成功。

## 验收范围

### 修后验收与守护文案运行时

用户在映射顺序修正后明确“模糊档位已验收，可以继续”。记录本机圆角、三档材料组合及修后顺序的人工验收，不继续把该已验收组合无条件标为未验证。守护文案接入限于实际验收的 macOS 27.0.1（26A434）、arm64、单显示器、2 倍比例、普通 layer 0 顶层窗口、外扩矩形完整位于显示器内、正常透明度/对比度设置；其他系统、比例、多屏、跨屏、屏幕边缘、sheet/全屏支持继续待测。

运行时只有当前权限/焦点/时段允许且唯一窗口几何有效、panel 呈现与窗口几何匹配、下一次自然 CG 快照确认 panel 在目标之上且扩大区域无夹层冲突时，才签发当前窗口/目标 bounds/所选档位/本机验收 revision 的 observation。新 panel 和移动/缩放重建后的首轮仍只是请求，不显示文字。设置变化使旧证据失效，需重新检查；文字开关单独变更不撤材料。消费端核对身份、几何、档位与 revision，全部成功才显示已保护，部分失败保持成功窗口文案并报告影响范围。权限撤回、聚焦、暂停、非保护时段和未知状态不能保留文字。

该 revision 代表本机人工验收的材料配置与严格运行时检查，不是 CG 元数据自行证明像素不可读，不新增人工确认按钮或通用“验证返回 true”工厂。跨版本、三人发行评估、帧时延和安全动画仍不宣称通过，后续验收限制保留。

检查成功保存与失败保存的下发差异、初始化设置、三档材料更新、开关不撤层、前台/暂停/非保护时段清理、小窗隐藏/窗口中心布局、未知状态不显示文字和不报成功。安装最终产品并核对 GUI；不保存用户窗口像素或变更用户配置做视觉观察。实际三档可读性、边缘强度、三人独立评估与时延仍待验证后放行守护文案与成功状态。

## 守护文案完成记录

在本机已验收材料 profile 下，`MaterialOverlayCoordinator` 仅在下一次自然 CG 快照确认顺序无冲突、target/expanded panel bounds 精确匹配、AppKit panel 已显示且实际 frame/scale 匹配时签发窗口 key、目标 bounds、当前档位和 `local-material-2026-10-14-v2` revision。新 panel 首轮不显示文案，档位改变会失效旧证据；文字开关不撤材料。`WindowProtectionCoordinator` 核对证据身份、唯一几何、档位、revision 及当前保护 intent，全部成功才显示已保护；至少一个成功且其他窗口失败或缺证据则部分失败。
