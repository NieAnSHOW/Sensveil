# Sensveil MVP 验证边界

日期：2026-10-12。实现基线：`d505e43`（菜单栏 MVP 外壳）。结论：**自动化规则与本机构建通过；真实模糊未验证，不能放行隐私保护或商业发布。** 本文不改变 [PRD](../product/PRD.md) 的验收门槛；历史实验观察见 [POC_RESULTS](POC_RESULTS.md)，不得把旧 PoC 权限和画面观察移作当前 Sensveil 二进制的证据。

## 当前实现范围

SwiftPM 包包含菜单栏 `Sensveil.app`、诊断 `SensveilPoC.app` 和合成内容 `SensveilFixture.app`。产品外壳提供中文管理页、应用搜索/添加/删除、最多 2 个配置条目、单应用开关、全局暂停/恢复、版本化本地配置和权限诊断。关闭管理窗口保留菜单栏进程；登录启动选项当前禁用。

窗口运行时连接焦点、窗口跟踪、权限轮询和材料覆盖请求。`behindWindow` 材料请求提交、窗口可见属性、CG 层级元数据均不证明合成像素已可靠模糊。当前材料请求仍显示“无法保护”，详情说明“模糊效果尚未验证”；部分窗口问题显示受影响状态。没有视觉证据时不得显示全部“已保护”，也不得降级为不透明遮罩。

ScreenCaptureKit、支付、120 小时试用、激活服务、永久离线验签、Developer ID 签名、公证、自动更新与商业分发尚未实现。免费配置额度的规则测试不证明整个商业版本已完成。
