## 2026-10-11 PRD 评审采用的基线

用户确认“没问题，可以继续”。以下产品规则作为下一阶段基线；这不表示系统可行性已验证，也不替代收费前的商业细则决策。

| 决策 | 采用的基线 | 实现需保证 |
| --- | --- | --- |
| 应用级还是窗口级焦点 | 按前台应用，同应用全部窗口共同撤层 | 同应用窗口切换不会单独模糊 |
| 免费额度的含义 | 最多配置 2 款，未运行/关闭也计数；允许删除替换 | UI、到期策略与售卖表述一致 |
| 试用起算 | 首次启动起连续 120h，权限等待计入 | 统一起算与到期行为 |
| 本地试用保证强度 | 首发离线、Keychain 尽力保留，不承诺防系统重装 | 严格一次仍须另确认首次试用联网 |
| 到期应用选择 | 保留配置，添加顺序前 2 条生效，可替换 | 超额项明确提示未保护 |
| 登录启动 | 默认关闭，由用户开启 | 不隐含创建登录项 |

代码许可目前保留版权，未授予开源许可；如需 MIT/GPL 等仍须产品所有者明确决定。

## 2026-10-13 防窥效果与保护时段基线

本轮实现（见 [实施计划](../superpowers/plans/2026-10-13-protection-effects-and-schedule.md)）采用的固定规则；如用户改变这些规则，先修改 TASK/PRD 与相应测试，不将新语义藏在代码里。

| 决策 | 采用的基线 | 实现需保证 |
| --- | --- | --- |
| 模糊档位 | 标准/增强/最强三档，默认标准；无连续滑块。2026-10-14 用户验收功能并反馈排序，材料调整为 hudWindow / popover / underWindowBackground，底层 popover 不变 | 本机观察不代替跨系统、独立可读性和安全动画验收；每档真实模糊路径，达到隐私不可辨读基线才可发布 |
| 守护文案 | 默认显示，可全局关闭 | 仅出现在已验证保护窗口的几何中心；关闭只影响文字 |
| 圆角覆盖（2026-10-14 用户批准更新） | 统一 20pt 圆弧、每边外扩 8pt，完整包围目标矩形；接受外围小范围模糊 | 不提供半径调节，不标称系统官方数值；扩大范围参与第三窗检查，无效几何或真实冲突失败；见 [ADR-002](../architecture/ADR-002-expanded-rounded-overlay.md) |
| 过渡动画（2026-10-14 最新更新） | 用户反馈效果不佳，隐藏四档选择，产品统一200ms；保留四档实现和schema3存储兼容 | 旧500/800/off不影响当前运行，不强制覆写用户文件；系统减少动态效果优先；不把隐藏功能当视觉验收通过 |
| 保护时段 | 全天（默认）/指定时段；预置周一至周五 09:00–18:00 | 模式切换不重置数据；7 天全空合法且明确提示 |
| 时段语义 | 左闭右开；支持多区间、跨午夜、重叠合并；跨日区间归属开始日 | 结束 24:00 为次日 00:00；零长度拒绝；不回绕丢尾段 |
| 时区与 DST | 本机时区墙钟分钟判断 | 春跳不补足，秋返两次同判；不加固定 86400 秒 |
| 节假日日历 | 随应用版本内置，离线判定；跟随默认关闭 | 缺年退回每周规则并独立警告，不复用旧年安排；无热更新/联网 |
| 状态优先级 | 超额 → 未开启 → 暂停/挂起 → 未运行 → 非保护时段 → 前台 → 窗口结果 | 非保护时段不冒充无法保护；日历警告独立展示 |
| 保护证据 | 只有真实模糊保护证据才显示“已保护/守护中” | 请求提交、回调成功、panel 存在、绘制完成均不是证据 |
