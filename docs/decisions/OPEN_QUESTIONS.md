## PRD 评审时确认

| 决策 | 当前建议 | 不确认的影响 |
| --- | --- | --- |
| 应用级还是窗口级焦点 | 按前台应用，同应用全部窗口共同撤层 | 保护范围与交互会不同 |
| 免费额度的含义 | 最多配置 2 款，未运行/关闭也计数；允许删除替换 | UI、到期策略与售卖表述不一致 |
| 试用起算 | 首次启动起连续 120h，权限等待计入 | 无法统一到期行为 |
| 本地试用保证强度 | 首发离线、Keychain 尽力保留，不承诺防系统重装 | 若要求严格一次，须另确认首次试用联网 |
| 到期应用选择 | 保留配置，添加顺序前 2 条生效，可替换 | 静默失去保护风险 |
| 登录启动 | 默认关闭，由用户开启 | 影响隐私保护与启动预期 |
| 代码许可 | 目前保留版权，不擅自授予开源许可 | 如要 MIT/GPL 等，需产品所有者明确决定 |

## PoC 后固化

| 决策 | 候选 | 门槛 |
| --- | --- | --- |
| 模糊路径 | NSVisualEffectView；失败再验证 ScreenCaptureKit + Core Image | 真实文字不可辨识、正确层级、单击聚焦 |
| 最低系统与 CPU 架构 | macOS 14，Apple Silicon + Intel | 公开 API 可用、真机支持矩阵通过 |
| 全屏/Spaces/Stage Manager 支持 | 仅宣传已验证场景 | 异常场景明确提示，无静默成功状态 |
| 采样/轮询预算 | 事件优先，必要时低频校准 | 延迟、CPU/内存及隐私测量通过 |
| 许可证后端 | TypeScript + Cloudflare Workers + D1 | 原子名额约束、幂等、签名兼容和备份验证 |

## 收费发行前必须确认

| 项目 | 建议与约束 | 负责人 |
| --- | --- | --- |
